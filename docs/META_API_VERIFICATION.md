## Access tokens (affects the connection design)

- A business accessing **its own** WhatsApp account should use a **System User access token** created in Business Settings > System Users with the permissions `business_management`, `whatsapp_business_management`, `whatsapp_business_messaging`. Tokens can be long-lived. (`WA/access-tokens`)
- A SaaS acting **for other businesses** (Tech Provider) uses Embedded Signup and Business Integration System User tokens.
- Webhooks are configured per Meta **app** (App Dashboard > WhatsApp > Configuration: callback URL + verify token), and the WABA must subscribe the app via `POST /{waba-id}/subscribed_apps`. The signature uses that app's secret. (`WA/webhooks/create-webhook-endpoint`, `WA/reference/whatsapp-business-account/subscribed-apps-api`)

Decision (2026-10-01): the platform uses **Embedded Signup as a Tech Provider** (see docs/META_SETUP_GUIDE.md). One platform app, one app secret (`WHATSAPP_APP_SECRET`) for webhook signatures, one callback URL; each customer's business token is stored encrypted per WhatsApp account.
